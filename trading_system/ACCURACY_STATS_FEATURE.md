## 📊 统计维度

### 1️⃣ **策略统计**

| 指标 | 说明 |
|------|------|
| **总信号数** | 策略生成的信号总数 |
| **盈利/亏损** | 盈利和亏损的信号数量 |
| **胜率** | 盈利信号 / 总信号 × 100% |
| **平均盈亏** | 所有信号的平均盈亏百分比 |
| **总盈亏** | 所有信号的累计盈亏 |

**示例**:
```
策略名                      总数    胜率      平均盈亏    总盈亏
--------------------------------------------------------------------------------
Bollinger Mean Reversion    15     60.0%     +2.35%     +35.25%
Prev High/Low Breakout      12     58.3%     +1.85%     +22.20%
RSI Overbought/Oversold     10     50.0%     +0.95%     +9.50%
```

---

### 2️⃣ **AI 统计**

#### 总体统计

| 指标 | 说明 |
|------|------|
| **总判断数** | AI 评分的总次数 |
| **正确/错误** | 判断正确和错误的次数 |
| **准确率** | 正确判断 / 总判断 × 100% |
| **平均置信度** | AI 的平均置信度分数 |

#### 按方向统计

| 方向 | 说明 |
|------|------|
| **LONG** | AI 建议做多的准确率 |
| **SHORT** | AI 建议做空的准确率 |
| **WAIT** | AI 建议观望的准确率 |

**AI 判断正确的定义**:
- **LONG/SHORT**: 信号最终盈利 (pnl > 0)
- **WAIT**: 信号最终亏损或持平 (pnl ≤ 0)

---

### 3️⃣ **对比分析**

#### 一致性统计

| 指标 | 说明 |
|------|------|
| **总信号数** | 既有策略置信度又有 AI 评分的信号 |
| **策略&AI 一致** | 策略方向和 AI 方向相同 |
| **策略&AI 分歧** | 策略方向和 AI 方向不同 |

#### 胜率对比

- **一致时胜率**: 策略和 AI 一致时的胜率
- **分歧时胜率**: 策略和 AI 分歧时的胜率

## 💾 数据来源

**数据库**: `cache/trading.db` (signals 表)

**查询条件**:
```sql
SELECT 
    symbol, strategy_name, direction,
    entry_price, exit_price, 
    exit_reason, pnl_pct,
    confidence, ai_score, ai_direction,
    created_at, exit_time
FROM signals
WHERE status IN ('STOP_LOSS', 'TAKE_PROFIT', 'CLOSED')
AND created_at >= datetime('now', '-30 days')
```

## 🧮 计算方法

### 策略胜率

```python
胜率 = (盈利信号数 / 总信号数) × 100%
盈利信号数 = pnl_pct > 0 的信号数量
```

### AI 准确率

```python
# 对于每个 AI 评分
if ai_direction == 'LONG' or ai_direction == 'SHORT':
    ai_correct = (pnl_pct > 0)  # 赚钱=正确
elif ai_direction == 'WAIT':
    ai_correct = (pnl_pct <= 0)  # 信号亏钱=观望正确

准确率 = (正确判断数 / 总判断数) × 100%
```

### 一致性判断

```python
if ai_direction == strategy_direction:
    一致
elif ai_direction != 'WAIT':
    分歧  # AI 不是观望且方向不同
```

## 📈 使用场景

### 1. 评估策略表现

- 查看哪个策略胜率最高
- 查看哪个策略总盈亏最高
- 优化或淘汰表现差的策略

### 2. 评估 AI 判断

- AI 整体准确率如何
- AI 在哪个方向上更准确（LONG/SHORT）
- AI 置信度是否可靠

### 3. 优化交易决策

- **一致时加仓**: 策略和 AI 一致时胜率高，可以增加仓位
- **分歧时减仓**: 策略和 AI 分歧时胜率低，减少仓位或观望
- **过滤信号**: 只用高胜率的策略
