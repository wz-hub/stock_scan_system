## 📊 新增功能：表格清单

### 功能说明

在信号卡片之前，新增**表格清单**选项卡，以数据表格形式展示所有信号。

### 显示列

| 列名 | 说明 | 格式 |
|------|------|------|
| 时间 | 信号生成时间 | YYYY-MM-DD |
| 币种 | 交易标的 | TURBOUSDT |
| 策略 | 策略名称 | Bollinger Mean Reversion |
| 方向 | 做多/做空 | LONG/SHORT |
| 价格 | 入场价格 | $0.001221 |
| 置信度 | 策略置信度 | 90% |
| AI 判断 | AI 评分结果 | ✅ LONG (65%) / ❌ SHORT (72%) / ⏸️ 观望 |

### AI 判断标识

| 标识 | 说明 | 颜色 |
|------|------|------|
| ✅ LONG (65%) | AI 同意，建议做多 | 绿色 |
| ❌ SHORT (72%) | AI 反对，建议做空 | 红色 |
| ⏸️ 观望 (60%) | AI 建议观望 | 橙色 |
| ⚪ 未评分 | 无 AI 评分数据 | 灰色 |

## 💾 数据库结构

### signals 表

```sql
CREATE TABLE signals (
    id INTEGER PRIMARY KEY,
    signal_id TEXT UNIQUE,
    symbol TEXT,
    timeframe TEXT,
    strategy_name TEXT,
    action TEXT,
    direction TEXT,
    entry_price REAL,
    stop_loss_price REAL,
    take_profit_price REAL,
    confidence REAL,
    reason TEXT,
    position_pct REAL,
    status TEXT,
    
    -- AI 评分字段
    ai_score INTEGER,
    ai_direction TEXT,
    ai_reason TEXT,
    
    created_at DATETIME
)
```
