---

### 2️⃣ **新增技术指标**

| 指标 | 说明 | 作用 |
|------|------|------|
| **MACD 柱状图** | 具体数值 | 精确判断动量变化 |
| **ATR (波动率)** | 平均真实波幅 | 评估风险和市场波动 |
| **布林带位置** | 0-1 之间 | 判断价格在通道中的相对位置 |
| **成交量比率** | 当前/平均 | 识别异常放量 |

**计算公式**:
```python
# ATR (14 周期)
ATR = MA(True Range, 14)
True Range = max(high-low, abs(high-close.prev), abs(low-close.prev))

# 布林带位置
BB_Position = (close - lower) / (upper - lower)
# 0 = 下轨，0.5 = 中轨，1 = 上轨

# 成交量比率
Volume Ratio = current_volume / MA(volume, 20)
```

### 3️⃣ **❌ 移除支撑/阻力位**

**原因**: 
- AI 可以自己从 K 线看出高低点
- 策略本身已经计算过关键位置
- 减少 token 浪费

**效果**: 每 prompt 减少 ~20 tokens

---

### 4️⃣ **❌ 移除策略偏见**

**重要原则**: AI 不知道策略的方向和置信度

```json
{
  // ❌ 不包含 direction (策略建议的方向)
  // ❌ 不包含 strategy_confidence (策略的置信度)
}
```

**作用**: AI 完全独立判断，不受策略影响，提供真正的"第二意见"。

**对比验证**:
- 策略说 LONG，AI 说 SHORT → 说明有分歧，需要谨慎
- 策略说 LONG，AI 也说 LONG → 双重确认，可以加仓
