## ⚠️ 风险控制

### 仓位管理

```
单笔交易：10% 仓位
最大持仓：50%（5 个信号）
单日最大亏损：5%（停止当天交易）
```

### 止损规则

```
硬止损：2.5%
时间止损：5 天（5 天后强制平仓）
追踪止损：盈利 5% 后，止损上移到成本价
```

### 异常情况处理

**连续亏损：**
- 3 连亏 → 减半仓位（10% → 5%）
- 5 连亏 → 暂停交易 1 天
- 7 连亏 → 暂停交易 1 周，检查策略

**市场异常：**
- 暴跌 >10% → 暂停交易
- 流动性枯竭 → 暂停交易
- 交易所故障 → 暂停交易
