   - 外链数量 → AI 看质量不看数量

   - 内容变得机械

3. **期望速成**
   - GEO 效果需要 3-6 个月显现

4. **只盯着一个 AI**
   - 不同平台都要测试
   - ChatGPT、Claude、Perplexity、豆包...

### ✅ 正确做法

1. **为人写，顺便为 AI 优化**
   - 人喜欢看，AI 也喜欢
   - 不要本末倒置

2. **数据驱动**
   - 测试→分析→迭代
   - 不凭感觉

3. **长期主义**
   - 持续产出好内容
   - 积累权威性

## 七、我的最终建议

### 🎯 首本推荐组合

```
题材：都市系统文 / 重生爽文
平台：番茄小说（流量大）/ 七猫（买断稳定）
字数：100-150 万字
更新：日更 4000-6000 字
目标：完本 + 签约 + 月入 3k+
```

### 🎯 心态建议

```
1. 首本不要想赚钱，先练手
2. 完本比成绩重要（证明你能写）
3. 多看书（拆解爆款套路）
4. 坚持更新（断更=死书）
5. 接受扑街（90% 新人首本都扑）
```

### 🎯 学习路径

```
第 1 个月：
- 看 10 本爆款（同类型）
- 写大纲 + 存稿 3 万字
- 开书

第 2-6 个月：
- 稳定更新
- 根据读者反馈调整
- 完本

第 7 个月：
- 复盘首本（得失）
- 开第二本（优化）
- 目标：月入过万
```
